JSON 基础 · 解析与序列化

① JSON 语法结构 格式规范
JSON 键必须用双引号，字符串也用双引号，不允许注释、undefined、函数。
{
  "name": "张梓轩",
  "age": 18,
  "hobbies": ["编程", "游戏", "桌游"],
  "score": {
    "html": 95,
    "js": 88
  },
  "isStudent": true,
  "address": null
}
