JavaScript 定时器

① setInterval — 重复执行 setInterval / clearInterval
// 每 1000ms 执行一次
var timer = setInterval(function() {
  clock.textContent = new Date().toLocaleTimeString();
}, 1000);

// 停止
clearInterval(timer);
--:--:--
② setTimeout — 延迟执行一次 setTimeout / clearTimeout
// 3 秒后执行一次
var t = setTimeout(function() {
  out.textContent = '⏰ 3 秒时间到！';
}, 3000);
点击「启动」按钮，延迟时间到后会显示消息
③ 进度条（setInterval + 清除）实际运用
0%
点击「开始加载」观察进度条变化
④ 倒计时（setInterval + clear）实际运用
10
点击按钮开始倒计时
⑤ setInterval 连续动画 颜色循环
setInterval 改背景色 → 产生动画
⑥ 嵌套与清理（重要！）坑点提醒
// ❌ 坑：每次 setInterval 又套 setTimeout
//    会生成越来越多的定时器，内存泄漏
setInterval(function() {
  setTimeout(fn, 1000);
}, 1000);

// ✅ 对的：定时器都要有 id，存起来
var id = setInterval(fn, 1000);
clearInterval(id);   // 组件销毁 / 页面离开时清理
点击按钮观察清理过程
